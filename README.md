# TaskBloom 🌸

A beginner-friendly to-do list web app built with **HTML, CSS, and vanilla JavaScript**.

## Features
- Add, complete, and delete tasks
- Filter by All, In progress, and Completed
- Live completion count and progress bar
- Clear completed tasks
- Dark/light theme toggle
- Saves tasks and theme in browser `localStorage`
- Responsive layout and CSS animations

## Run the project
1. Extract `TaskBloom.zip`.
2. Open the `TaskBloom` folder.
3. Double-click `index.html` to open it in your browser.

No installation, framework, API key, or internet connection is required.

## What to explain during your presentation
- **HTML** creates the page structure and controls.
- **CSS** handles colors, layout, responsive design, dark theme, and animations.
- **JavaScript** adds tasks, marks tasks complete, filters the list, updates progress, and deletes tasks.
- **localStorage** saves tasks and the selected theme in the browser, so data stays after refresh on the same browser.

## Notes
Tasks are saved only in the browser/device where you use the app. Clearing browser site data may remove them.
